# EcoBrief AI 🌿🤖
*Understand Environmental News in Less Time*

EcoBrief AI is a web application designed to combat information overload by taking long environmental news articles and instantly generating short summaries, key extraction points, and automated topic categorizations.

## ✨ Key Features
* **Dual Engine Support:** Switch between AI Mode and Rule-Based processing.
* **Quick Samples:** Pre-loaded sample articles for Climate Change, Air Pollution, Renewable Energy, Wildlife, and Water.
* **Instant Insights:** Generates clean summaries and word-count statistics.

## 🛠️ Technologies Used
* **Frontend:** HTML, CSS, JavaScript / Modern Web Framework
* **Engine:** AI & Rule-Based Dual Processing Logic
